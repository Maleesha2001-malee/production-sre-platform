
# Production SRE Platform

## Project 01: Server Health Monitoring

A Python-based Linux monitoring tool.

### Features
- CPU monitoring
- RAM monitoring
- Disk monitoring
- System uptime
- Resource threshold alerts

### Technologies
- Python
- Linux
- psutil

## How to Run

```bash
sudo apt install python3-psutil -y

python3 automation/python/server_monitor.py
```
